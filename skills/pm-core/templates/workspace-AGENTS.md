# OpenPM workspace

This is a private **OpenPM** workspace. It holds the user's clients,
requirements, roadmaps, tasks, and journal.

- The suite and its rules live in the `pm-core` skill (from the OpenPM repo).
  Read it before you change anything here.
- Layout and task format: `pm-core/references/workspace.md`.
- The user owns client communication and decisions. Agents draft. They do not
  send messages or make commitments.
- This repo contains confidential client information. Never copy it into
  public repos, issues, or gists.
